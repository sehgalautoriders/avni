Download the latest AVNI Phone

  1. Tap the orange button. The file AVNI-Phone.apk downloads.
  2. Open it from the notification (or Files → Downloads).
  3. If the phone says "not allowed", tap Settings → turn on "Allow from this source" → go back.
  4. Tap Update (or Install), then Open. Your messages and settings stay — it installs over the old one.
  5. If "Play Protect" warns about an unknown app: tap More details → Install anyway. The app is ours, not from the Play Store, so Google shows this once.

Every new version is put here the same day. Open this page again whenever you want the newest one — the version number above tells you what is here now.
